# Cataclysmic Cooking!
This project is survival cooking game where the visitors that come in are not what they seem.


# How to Play
Goal of the game is to survive for as long as possible by cooking food and eat it. You have to plant and grow your own food while making sure you are constantly repairing your bunker.

## How the project was made
This project was made with godot and gdscript
